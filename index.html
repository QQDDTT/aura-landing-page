大道至简：开发者体验

仅需三行代码，唤醒宇宙

不再需要繁琐的中间件和连接池配置。Aura 将所有底层通信逻辑封装在物理基座内，您只需要关注业务流演进。

查看完整 API 文档
use aura_core::prelude::*;

fn main() {
    // 1. 初始化隔离沙箱
    let substrate = Substrate::new("prod-env");
    
    // 2. 挂载认知皮层
    let cortex = Cortex::attach(&substrate);
    
    // 3. 启动并连接二进制总线
    cortex.ignite(AcpBus::default()).await.unwrap();
}
